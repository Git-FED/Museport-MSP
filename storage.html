The storage argument, with its math showing.

Back-of-envelope examples

  • About 31,000 photos at 4 MB each.
  • About 250,000 web images at 500 KB each.
  • About 20 billion words at roughly 6 bytes per word.

These are approximate arithmetic illustrations, not capacity planning. Real usable space depends on filesystem overhead, backups, duplicates, file size mix, quotas, availability, and the storage provider’s terms.

Compare carefully

The brief compares the reported disk figure to Supabase free file storage (1 GB) and Cloudflare R2 free allowance (10 GB). Confirm current public pricing, eligibility, limits, and the exact meaning of each quota before making a migration decision. Disk on a computer is not automatically equivalent to durable, public object storage.

Capacity is only one part of hosting. Durability, access, security, uptime, bandwidth, backups, and a stable public URL matter too.

What this project does

It stores no user content. It is a static concept site with local project assets. It does not connect to Muse, Cloudflare, Supabase, or any storage API.
