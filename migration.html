MUSE HOSTING / MIGRATION

A migration is a checklist, not a leap of faith.

The long-term vision mentions moving fedpromptly.com away from current providers. This page sets out a cautious sequence and does not perform DNS, account, or data changes.

Before changing anything

  • Inventory pages, assets, data stores, forms, auth, API calls, scheduled work, DNS records, email records, and third-party dependencies.
  • Export data and verify restorations from a separate copy.
  • Build and test a faithful staging copy using synthetic or safely copied data.
  • Confirm legal, security, availability, domain, and provider-term requirements.

Cutover sequence

  1. Prepare the new environment and confirm HTTPS, routes, redirects, 404 behavior, and monitoring.
  2. Lower DNS TTL ahead of time where appropriate; record existing DNS values first.
  3. Synchronize the final data, validate checksums and critical user flows.
  4. Switch traffic only after an explicit owner-approved change window.
  5. Monitor, preserve the old environment, and document a tested rollback path.
Do not cancel existing services until the new location is verified, backups restore successfully, and a rollback window has passed.

GitHub Pages + Cloudflare

The requested distribution target is a static GitHub repository deployable through GitHub Pages or Cloudflare Pages/Workers static assets. This bundle is framework-free: relative links, HTML pages, CSS, JavaScript, SVG, and PNG files. Choose one deployment path at a time and follow its current platform docs; no platform configuration or credentials are included.
